# 🏥 Healthcare Data Analytics Dashboard

**An Interactive Healthcare Analytics Solution | Microsoft Excel | Data Analysis | Data Visualization**

## 📌 Project Overview

This project focuses on analyzing healthcare data and transforming raw datasets into meaningful, actionable insights through interactive dashboards built using Microsoft Excel.

The dashboard provides a consolidated view of key healthcare metrics, patient trends, financial performance, recovery outcomes, and ICU utilization. It is designed to support data-driven decision-making by presenting complex information in a clear and interactive format.

## 🎯 Business Objective

The primary objective of this project is to understand healthcare operations through data analysis and identify meaningful patterns that can help stakeholders:

- Monitor patient admissions and healthcare trends.
- Evaluate treatment costs and financial performance.
- Analyze patient recovery outcomes.
- Understand ICU utilization and patient distribution.
- Track important healthcare KPIs through interactive reporting.

## 📊 Dashboard Modules

### 1. Executive Overview
Provides a consolidated view of key healthcare performance indicators (KPIs), enabling quick assessment of overall healthcare operations.

### 2. Patient Analysis
Explores patient demographics, admission patterns, and patient distribution to identify trends in healthcare service utilization.

### 3. Financial Analysis
Evaluates treatment expenses, billing information, insurance coverage, and pending payments to understand financial performance.

### 4. Recovery Analysis
Examines patient recovery patterns and treatment outcomes to gain insights into healthcare service effectiveness.

### 5. ICU Analysis
Analyzes ICU admissions, patient distribution, and ICU utilization to understand critical-care requirements and operational trends.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data analysis and dashboard development.
- **Pivot Tables** – Data summarization and aggregation.
- **Pivot Charts** – Visual representation of analytical findings.
- **Slicers** – Interactive filtering and dynamic reporting.
- **Excel Formulas** – KPI calculations and data analysis.
- **Data Cleaning** – Preparing datasets for accurate analysis.

## 🔍 Analytical Approach

The project follows a structured data analytics workflow:

1. **Data Understanding:** Examined the available healthcare dataset and identified relevant fields.
2. **Data Preparation:** Reviewed data quality and prepared the data for analysis.
3. **Data Analysis:** Used Pivot Tables, Excel formulas, and aggregations to analyze healthcare metrics.
4. **KPI Development:** Created performance indicators to summarize important business metrics.
5. **Dashboard Development:** Built interactive dashboards using Pivot Charts and Slicers.
6. **Insight Generation:** Interpreted visual trends to understand patient, financial, recovery, and ICU performance.

## 💡 Key Analytical Areas

- Patient admission and distribution trends.
- Healthcare expenses and insurance analysis.
- Recovery rate and treatment outcome analysis.
- ICU utilization and patient trends.
- Pending payment and financial monitoring.


## 📈 Project Outcome

Developed an interactive, multi-section healthcare analytics solution that organizes healthcare data into meaningful KPIs and visual reports. The project demonstrates practical application of Excel-based data analysis, reporting, and dashboard development.
